# Blackboard 课程回放转文字

把 Blackboard 课程回放的音频转成带时间戳的文本，方便用 AI 总结课程内容和课后复习。目前适配北大教学网的 Blackboard 回放，也支持本地音视频文件。

## 使用方法

1. 在装有 Microsoft Edge 和 Python 3.10 或更新版本的 Windows 电脑上，双击 **转写课程回放.cmd**。
2. 粘贴教学网回放网址，或拖入本地音视频文件，然后按回车。首次处理回放或登录过期时，在弹出的 Edge 窗口登录教学网。
3. 在项目目录的 **文字稿** 文件夹查看生成的 TXT。

首次运行会安装 Python 依赖并下载 Whisper 模型。转写在本机完成，默认识别中文。可用的 NVIDIA GPU 和 CUDA 运行库会用于加速语音识别，其余情况使用 CPU。音频提取和转写约每处理 10 分钟的课程内容更新一次进度。

如果播放器需要手动开始，点一下播放即可。工具找到音轨地址后会暂停网页，直接读取完整音轨。在 PowerShell 中运行 `.\转写课程回放.cmd --help` 可查看语言、模型和运行设备等选项。
